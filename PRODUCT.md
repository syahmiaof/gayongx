# Product contract

This existing React + TypeScript + Vite app is a frontend-only PSSGM Perak ecosystem demonstration. The user supplied the complete brief and approved proceeding without stage approvals.

- Public visitors: find the organisation, discover programmes and gelanggang, check demo membership and join a demo flow.
- Members: inspect synthetic profile, membership, belts, digital card, programmes and notifications.
- Administrators: inspect synthetic statistics, filter charts, review local approvals and create demo programmes.
- No database, authentication server, payment gateway or backend integration.
- All member, officer, event and statistical records are DEMO_SYNTHETIC. Supplied organisation wording is retained as reference content, not newly independently verified.
- Supplied logo must be used unmodified. Extracted reference imagery is demo presentation, never historical evidence.
- Required visual authority: ../ui website.jpg, ../ui user.jpg, ../ui admin.jpg. Exact headline uses WARISAN SILAT SENI.
- Success: close screenshot composition at desktop, functional local interactions, mobile containment, successful install/typecheck/build.
